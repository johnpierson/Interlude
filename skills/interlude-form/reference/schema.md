# The Interlude form schema

Generated from the Interlude assembly by `Interlude.Preview --schema`. Every property here is one the reader accepts, spelled the way it accepts it. Do not edit this file.

Schema version **1**. A file whose `schemaVersion` is higher is refused outright rather than partly understood, so always write the version above.

## The document

A whole form, as data.

| Property | Type | Default | Meaning |

| `window` | [WindowOptions](#windowoptions) | the WindowOptions defaults |  |

## Rules

The entries in an element's `rules`, applied while the user types.

### Shared by every rule

One check applied to one field's value. Rules can read the rest of the form through `Conditions.IFormStateReader`, so "end date must be after start date" is expressible; declaring those extra keys in `ValidationRule.DependsOn` is what makes such a rule re-run when the *other* field changes.

| Property | Type | Default | Meaning |
| --- | --- | --- | --- |
| `message` | string |  | Overrides the rule's built-in wording. |
